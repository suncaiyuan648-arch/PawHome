### R04 / P1：任务列表仍有归属冲突，审核任务无法进入详情

- `packages/account/services/tasksRuntime.ts:87` 的 actorOwns 仍在 applicantId/applicantUserId/userId/ownerPawId 中取任意匹配；新增冲突检查只覆盖部分字段。独立记录 id=application-b、applicantId=user-b、userId=user-a，被 user-a 接受为申请任务（accepted=1）。旧组合反例因额外 ID 冲突被挡住，不代表归属问题已修全。

退出条件：本地事件产生持久通知→接收者读取→当前业务详情；登录返回后恢复同一目标；旧阶段、删记录、越域明确失败；不重放写动作。

### R09 / P2：社交功能仍关闭，应记为决策/功能未交付而非完成

SOCIAL_MUTATION_UNAVAILABLE 以及本人关系门禁可以保留。A09 的本人动态/评论删除、失败恢复、普通内容与反馈证据区分并未成为页面能力。缺批准策略时保持关闭是正确的安全行为，但不构成“全部非视觉任务完成”；要么完成本轮策略/设计与本地实现，要么将获准继续关闭作为明确范围决策登记，不混入 DONE。
