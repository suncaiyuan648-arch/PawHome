# C0-B2 包体、资源与依赖门禁验收

实施：Luna xhigh；额度中断后总工程师补齐动态 require/import、相对模板/样式路径、越出产物路径与失败报告反例。未提交 commit。

## 交付

- `scripts/check-package-{size,assets,boundaries}.cjs` 与 `scripts/lib/package-audit-*.cjs`。
- `config/package-budgets.json`、9 组测试。
- 总工接入 `check:package-size`、`check:assets`、`check:boundaries`、`check:package`、`check:package:final`，生产 build 自动执行三道门禁。

包归属只认产物 app.json；未注册的旧目录仍计入 main。报告包含精确 bytes/KiB、全量总计、各包 Top20、SHA-256 同内容组、可选 baseline delta。报告在 .artifacts/package-audit；失败会覆盖旧成功报告，报告不能写进被测产物。所有包硬限 2097152 bytes；migration 主包不得高于 1941174 bytes；final 主包 1572864 bytes，域预算和总计 8388608 bytes 同时检查。`--final` 或配置 phase=final 均能启动最终门槛，不能靠漏传 CLI 退回迁移模式。

资源检查覆盖编译 JS/WXML/WXSS/JSON/WXS/CSS 的静态本地资源、CSS URL/import、usingComponents、媒体相对路径；依赖检查包括模块 require/import、模板 include/import、wxs src、组件引用及样式 import。main→sub、sub→sibling、缺资源/模块、越出产物以及无法判定的计算 import 都失败。分包引用轻量主包代码允许。

源码审计检查 pages、packages 和根公共模块的 import，跳过构建/第三方依赖目录；使用字符串语法扫描而非完整 bundler 语义求值。报告给出依赖边，不把源码物理归属当作运行时权限证明。动态业务远程图片、JSON 数据运行时拼接、组件 props 传图及所有模板表达式不能靠此静态门禁证明正确，仍需运行时验收。

## 验收

9 组测试 PASS：精确阈值、幽灵 root、非法 root、最终阶段、重复内容、跨包/缺失/越界、相对路径、动态表达式、CLI 失败覆盖报告。集成构建的 migration size、assets、production/source boundaries 全部 PASS。最终 1.5MiB 门槛尚未达到；不改预算放行。
