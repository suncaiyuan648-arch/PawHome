## 数据与状态边界

页面只接受 `rescueId` query。MP-WEIXIN 边界调用总工提供的 `decodeWeixinLoadOptions` 一次，保留字面 `+` 与编码后的百分号；随后调用 `buildRoute('rescue.progress', params)` 做完整参数合同校验。坏编码、非法 ID、`type`/`frame` 等未知字段和非字符串参数进入 `invalid-params` 空态并在存储读取前返回；缺少 ID 显示 `missing-id` 空态。不会从 `id`、`recordId` 或历史最后一条记录推断救助单。`onLoad` 读取初始单据，`onShow` 显式再次刷新；每次刷新先清空旧记录。未找到显示“救助申请不存在”，缺失/无效参数都不渲染平台审核中内容。

唯一读取调用是 `getRescueById(this.rescueId, { includeDemo: false })`，页面没有导入 `applicationMockApi`。展示组合以 `applicationStatus` 和 `RESCUE_APPLICATION_STATUS_META` 派生 `platform_pending`、`platform_approved`、`platform_rejected`；未知状态显示不可识别状态，不回退为审核中。普通申请者页无审核、打款或提交操作。
