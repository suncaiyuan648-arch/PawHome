## Frozen bridge contract

`createSelectorBridge({ now?, idFactory?, defaultTtlMs? })` creates an isolated in-memory bridge. `now` and `idFactory` are injectable for deterministic tests. The default TTL is five minutes; a request TTL is a positive integer no longer than one day. The default ID factory includes a per-instance/session nonce as well as time and sequence, so separate bridges do not emit the same default ID under a shared clock. The nonce is only an in-memory collision boundary, not a permission token or cryptographic security primitive. When `idFactory` is injected, the caller owns the requirement to return globally unique IDs for that bridge lifetime.

`createRequest({ kind, callerId, context?, ttlMs?, onConfirm?, onCancel? })` accepts `kind` `address`, `region`, or `animal`. It returns:

```text
{ kind, requestId, callerId, expiresAt,
  bridge: 'eventChannel', autoRedirect: false }
```

The `bridge` field is metadata aligned with the existing route selector shape. It does not create an eventChannel, navigate, redirect, or persist data. `context` is deep-cloned and frozen in memory, passed as a separate second callback argument, and never included in the result or any URL. It must contain JSON-like plain values; prototype keys, cycles, functions, and non-finite numbers fail.

`confirm({ kind, requestId, result })` validates the pending request before consuming it. Callback result envelopes are frozen and contain the matching `kind` and `requestId` plus exactly one selector payload:

```text
address → { kind, requestId, addressId }
region  → { kind, requestId, parts: [one to four short region names] }
animal  → { kind, requestId, animalIds: [one to six unique restricted IDs] }
```

Region `parts` preserve the existing caller shape from `PawRegionPicker`: Chinese administrative names are accepted as short text (maximum 64 UTF-16 code units per part), one to four levels, with no empty/whitespace-padded/control-character values. Equal names at different levels are valid for cases such as `['北京市', '北京市', '朝阳区', '望京街道']`. Names, phone numbers, drafts, arbitrary objects, and unknown result fields are rejected; address and animal IDs use the restricted ASCII shape from the route contract. `cancel({ kind, requestId, reason? })` returns a `{ kind, requestId, reason }` cancellation envelope. `cancelCaller(callerId)` consumes every pending request for that caller, and `cleanupExpired()` consumes requests whose `expiresAt` has passed. Both invoke cancellation callbacks with `caller-destroyed` or `expired` respectively.

Every consume deletes the request before invoking user code. A callback exception is reported as `CALLBACK_FAILED`, while the request remains consumed; cancellation batches delete all matching requests before any callback runs. Wrong kind, unknown ID, duplicate generated ID, invalid result, expired request, restart-unknown request, and invalid caller/reason fail clearly without consuming an unrelated request.

Callbacks are synchronous by contract. Returning a Promise/thenable is rejected as `ASYNC_CALLBACK_UNSUPPORTED`; the request has already been consumed, and the bridge does not claim to catch later asynchronous exceptions or provide asynchronous delivery semantics.

## Verification

The test loader copies the ESM bridge into a temporary directory containing `package.tson` with `type: module` and dynamically imports it. No `uni`, storage, eventChannel, page, or fixture is stubbed or used.

```text
node --test tests/governance/selector-bridge.test.cjs
9 passed, 0 failed
```

The tests cover request shape and context isolation, all three selector result shapes, four-level Chinese region names and same-name levels, empty/long/control-character region parts, wrong kind/request, sensitive and unknown fields, identifier validation, duplicate IDs, parallel callers, batch caller destruction, expiration, callback reentrancy/exception, and two default-nonce bridges under the same clock where an old result cannot consume the new request.
