## 运行验证

在本工作树运行：

```text
node scripts/build-figma-state-matrix.cjs
node --test tests/governance/figma-state-matrix.test.cjs
```

结果：矩阵生成成功，41 个正式 states 均为 `mapped`；4 个设计状态保持 unresolved，9 个 component nodes 未计为页面；node:test 3/3 通过。

当前脚本直接 `require('yaml')` 解析 map、`require('json5')` 解析 pages.json。两者在当前 lock 的 node_modules 可用，但建议总工将 `yaml`（或统一的 `js-yaml`）明确提升为直接 devDependency，避免依赖传递安装。

## 给后续检查器的矩阵合同

JSON 的 `entries` 是正式状态行：`pageKey`、`stateKey`、`nodeId`、`route`、`source`、`query`、`targetUrl`、`routeOrigin`、`sourceOrigin`、`runtimeStatus`、`runtimeReason`、`status`、`errors`。`status=mapped` 只表示静态 map/注册/source/query 校验通过，不表示运行时或视觉通过；runtime 前置必须单独看 `runtimeStatus/runtimeReason`。失败报告的 `status=error` 与空 `entries` 优先于任何之前生成的报告内容。
