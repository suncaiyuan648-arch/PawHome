# C0-B1 资源管线验收

实施：Luna xhigh，额度中断后由总工程师完成反例修正与集成。基线 HEAD：80fef9f3c24066e7e7b50f2e9a374f60dd22582e。未提交 commit。

## 范围

`scripts/prepare-mp-weixin-package.cjs`、`tests/governance/package-assets.test.cjs`。读取 pages.json 的实际分包与编译后 app.json；根公共模块保守归主包，新 packages 根和旧 pages 根均支持。保留包内 static，不再全删；未知文件保留并报告，生产 dev 根与构建专用 mono 资产排除。

根路径只做精确匹配，查询/hash 保留，远程 URL、相似文件名前缀及包私有绝对路径不受根资产别名影响。不同内容的根/包同名资源明确报错。重复运行先还原自身的根资产搬运路径，再重算归属；同内容去重合并 owners 时只要主包需要，就统一在主包，避免再次生成不同分包副本。动态目录文件保留原名，不能通过字面量重写误删计算出来的文件名。

## 证据

6 组 fixture PASS：新旧根、传递/副作用引用、root/shared/private、同内容不同名、动态文件名、CSS 查询/hash、未知与跨包引用、dev 剔除、远程路径、同名冲突、失败覆盖旧报告、二次执行。独立工作树真实构建的 933 个文件二次处理 SHA-256 完全一致；证据 `pawhome-governance/c0-a2/.artifacts/c0-b3-idempotence.json`。

第一次真实构建曾超过 2MiB，拒绝验收；配套 C0-B3 明确资源清单与私有组件归属后，主工作区合入构建通过。压缩参数保持旧值，未降低图片质量换取通过。

## 限制

这不是任意 JavaScript 的完整资源求值器。有限动态图片应改为显式清单；不认识的动态引用由独立资源门禁失败，不能用“已打包目录”代替证明。分包相同路径不同内容暂明确拒绝，后续如需支持须新增精确语义合同。开发产物由 uni-app 原生复制/watch，生产后处理的包体数字只代表处理后的生产目录。
