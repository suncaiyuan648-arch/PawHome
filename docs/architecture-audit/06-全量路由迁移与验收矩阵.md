## 1. 状态、设计和入口的读法

- **保留**：现有主包 Tab 路径不变，治理其依赖、状态与调用合同。
- **迁移**：目标职责基本相同，路径语义/物理归属调整；旧生产路由保留兼容。
- **拆分**：旧页按已列出的上下文映射到多个目标；不能照搬旧多 mode 页面到新目录。
- **归并**：内容收敛到明确页面或弹层；不是删除用户能力。
- **QA/待确认**：默认不创建新的生产能力；保留开发验收能力，旧生产入口去留经过调用/外部链接核实。尚不能确认时保留安全兼容，不阻塞其他业务迁移。

设计必须从 `figma-map.yaml` 中找精确节点。本文出现的节点只是已在项目文档中有明确来源的定位提示。`待补 map` 表示本次没有正式 node→route 映射，不代表没有设计，更不允许自行猜节点。
