## 工作规则

- 子 agent 在独立工作树中实施；总工程师复查 diff、跑关键测试和反例、确认没有越界后才将通过的修改集成到主工作区。
- 一个批次失败即退回修复；子 agent 自报 PASS 不等于总工验收通过。
- 不自动暂存或提交用户原审计文档；本地集成不等于授权上传、支付或发布。
- 先 C0-A 检查/合同，再 C0-B 包归属和资源管线，随后业务域迁移。每次完成更新本台账，未验收任务不标完成。
- 运行时只复用已打开的微信开发者工具窗口；不自动开窗或重启实例。缺运行时证据必须标明。
