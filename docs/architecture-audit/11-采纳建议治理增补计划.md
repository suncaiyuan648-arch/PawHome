## 5. 需要先确定的业务规则

1. **云家长审核**：保留无云家长可跳过的现有条件。多个云家长按全员/任一/指定审核，以及超时如何处理，先从现有存储和设计提取，不能自行选定。验收数据必须覆盖 0/1/多云家长。
2. **补材料**：可补材料不是撤销拒绝。未形成批准状态表前保持 ADOPTION_REAPPROVAL_ENABLED=false；批准后用迁移 adapter 兼容旧记录，不能另造第二套大写状态替代现有表。
3. **订单隐藏**：使用 userId+orderId 可见性；订单、奖励来源、履约与反馈证据仍可被合法参与者读取。不承诺永久保留政策，不依赖 HTTP 动词决定数据语义。
4. **反馈证据**：业务键应区分同一请求重试与不同次合法反馈；策略版本、删除/撤回对任务计数的影响、证据留存/更正权限必须有确定合同。不得由前端常量决定云养期限和应反馈次数。
5. **待办展示**：普通申请人也有确认、补材料、奖励任务，不能因无审核角色隐藏全部任务。任务唯一键包含业务对象、阶段及处理 actor；角色标签不是访问凭证。
6. **资料/小院/动态编辑**：缺画板先交基于批准组件的设计规范与精确引用；隐藏设计层不自动成为可见按钮；已有管理态也不证明普通用户有管理权限。
