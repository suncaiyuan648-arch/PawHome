# 投喂订单详情

## 页面职责

`/packages/feeding/pages/order/detail/index` 只读取一个明确的 `orderId`，展示当前账号有权限看到的投喂订单摘要和个人隐藏状态。订单详情不负责支付、退款、再买、履约提交或修改订单。

订单类型由持久记录决定。`perspective` 只表达已授权的展示视角，不能替代 actor、订单归属或反馈权限。缺少、失效或无权读取的 `orderId` 显示不可用态，不回退到另一条演示订单。

## 兼容状态

历史 Figma 画板 90/91/92 由同一 canonical 页面通过 `variant` 承载本地/mock 视觉态：

- `variant=90`：投粮订单详情/个人视角。
- `variant=91&perspective=yard-manager`：院主视角与反馈入口。
- `variant=92`：云养与物流字段展示。

这些编号只用于状态展示和验收夹具，不授予读取、反馈或写入能力。真实订单读取优先于本地 mock；反馈仍回到动态编辑器并携带订单关联上下文。

- 院主反馈详情底部固定栏复用 `PawFixedActionBar`，左侧日历按钮使用与小院订单列表相同的 Figma `83:23732` 图标；点击后打开投喂模块复用的 `PawDatePickerSheet` 单独宠物反馈状态，对应 Figma `83:18955`。当天日期始终显示红色，其他选择日期显示绿色且不加黄色边框；日期区和订单信息区分别滚动，订单信息使用左右两列。选择日期只切换抽屉下方订单信息并保持抽屉打开。底部抽屉统一复用 `PawBottomSheet`。

## 验收要点

- `orderId` 缺失、格式错误、跨 actor 或隐藏记录均 fail-closed。
- 隐藏/恢复只改变当前用户的可见性偏好，重进页面后状态保持，院主履约读取不受影响。
- `PawPageNav` 提供导航几何；页面不绘制微信胶囊、状态栏或 Home Indicator。
- 375px 基准的逐状态视觉/几何验收另由最新 Figma 批次完成，不能由路由迁移门禁代替。
